#  Gulshan Kumar | Developer Portfolio

Welcome to my personal portfolio repository! This is a highly-premium, modern, and glassmorphic web application designed to showcase my projects, technical skills, and academic achievements.

 **Live Demo:** [https://Dynamic3728k.github.io/PORTFOLIOO](https://Dynamic3728k.github.io/PORTFOLIOO)

---

##  Features
- **Modern UI/UX:** Stunning dark theme with neon gradients and glassmorphism.
- **Dynamic Animations:** Smooth scrolling, page transitions, and hover effects powered by `framer-motion`.
- **Responsive Design:** Fully mobile-friendly layout that works perfectly on any screen size.
- **Iconography:** Rich technical icons using `react-icons` and `lucide-react`.

##  Tech Stack
- **Core:** React, Vite
- **Styling:** Custom CSS (Glassmorphism & CSS Variables)
- **Animations:** Framer Motion
- **Icons:** React Icons, Lucide React
- **Deployment:** GitHub Pages (`gh-pages`)

---

##  Running Locally

If you'd like to run this project on your local machine, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Dynamic3728k/PORTFOLIOO.git
   cd PORTFOLIOO
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
   *Open `http://localhost:5173` in your browser to view the application.*

---

##  Deployment

This project uses the `gh-pages` branch for hosting. If you fork this project or want to push new updates to the live site, simply run:
```bash
npm run deploy
```
